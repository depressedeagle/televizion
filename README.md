# Televizion

Приложение для просмотра видео с Rutube: лента по категориям, поиск, история просмотров, избранное, прогресс воспроизведения.

## Запуск

```bash
npm install
npm run dev
```

Одна команда `npm run dev` поднимает и API-сервер (порт 3001), и фронт (Vite, порт 5173). Откройте в браузере http://localhost:5173.

Отдельно:

- `npm run dev:server` — только сервер (прокси к Rutube).
- `npm run dev:client` — только фронт (Vite).

## Переменные окружения

- **Сервер** (папка проекта, файл `.env`):
  - `PORT` — порт сервера (по умолчанию 3001).

- **Фронт** (при сборке):
  - `VITE_API_BASE` — базовый URL API (по умолчанию `http://localhost:3001`). В продакшене укажите URL вашего бэкенда.

## Структура

- `server/index.mjs` — Express-сервер, прокси к Rutube API (лента по тегам, поиск). API-ключ не нужен.
- `src/` — React (Vite): лента, поиск, роутинг (`/`, `/video/:id`, `/search`), история и избранное (localStorage), категории, пагинация «Загрузить ещё», D-pad навигация, плеер с поддержкой старта с позиции (bmstart).

## Тесты

- `npm run test` — unit и компонентные тесты (Vitest).
- `npm run test:e2e` — E2E (Playwright; поднимает приложение и проверяет сценарий: лента → клик по карточке → плеер → назад).

## Сборка

```bash
npm run build
npm run preview
```

Для продакшена задайте `VITE_API_BASE` при сборке (например в CI) или настройте прокси к бэкенду.
